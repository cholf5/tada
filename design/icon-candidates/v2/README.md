# 第二批：材质 / 轻度拟物

第一批（`../` 下的 `A-gold` 等）全部保留，没有删除。
本批按“暖红 / 米色、纸与蜡的质感、轻度拟物”的方向重做，参考了 Wunderlist 的
暖色、纸张与手工感，但不使用它的名字、W 标记或任何原资产。

## 约束（与第一批相同）

- 1024 × 1024，纯几何 + SVG 渐变/图案/滤镜，无文字。
- 满幅底板；关键图形在半径 410 的 maskable 安全圆内。
- 判断尺寸仍是 16 / 24px：细节只在大尺寸加分，不能拖累小尺寸。
- 只在 48px 以上出现的细节（缝线、纸纹、扇贝边、金边）视为“加分项”，不是主体。

## 居中修正

这一批的墨迹（对勾 / t）都按**墨迹包围盒中心**对齐到 1024 画布中心；火漆印同时对
火漆圆盘中心 (512, 512)。用 sharp 实渲染后按像素反查过：

| 候选 | 修正前墨迹中心 | 平移 | 修正后 |
|---|---|---|---|
| 02 火漆印 | (547.5, 520) | (-35.5, -8) | (511.5, 511.5) |
| 05 签名火漆 | (520, 520) | (-8, -8) | (511.5, 511.5) |
| 03 纸与丝带 | (540, 530) | (-28, -18) | (511.5, 511.5) |
| 04 珐琅勾 | (565, 520) | (-53, -8) | (511.5, 511.5) |

01 笔记本的对勾**故意**放在书脊右侧：书脊占左侧 198px，内页区域中心约 611，
勾的包围盒中心 565，正好在内页偏左的视觉平衡位置，因此没有强行拉到 512。

原版保留为 `02-seal-a.svg`、`05-signet-a.svg`、`03-ribbon-b.svg`、`04-enamel-b.svg`。
03 的 mask 在去掉丝带剪口后已无作用，一并移除，平移只作用于内容组。

## 已否决的变体

| 文件 | 想法 | 否决原因 |
|---|---|---|
| `03-ribbon-a.svg` | 丝带端部做 V 形剪口 | 剪口太大，512 看着像一面旗，勾的识别反而丢了。 |
| `05-signet-flat.svg` | 火漆里换成平脚 t | 16px 更清楚，但少了手写印章的味道；留作备选。 |
| `04-enamel` 早期阴影 | 重投影 + 粗暗边 | 512 有“贴纸”感，24px 发脏；已把投影降到 0.3 左右。 |
| `01-notebook` 早期阴影 | 更黑更硬的投影 | 同上；改成更大模糊、更低不透明度。 |

## 技术说明

- 渐变、`<pattern>` 纸纹、`feDropShadow`、`<mask>` 都经过 `sharp`（librsvg）实渲染验证，
  与 `npm run icons` 的生产管线一致；预览图的 PNG 也是 sharp 出的。
- 每个候选的 16px 版本都单独检查过；安全圆内最远点均 < 410。
- 浅色底风险：`03-ribbon` 的米色纸底在浅色任务栏上最弱，但红色对勾仍然成立。

## 定稿后

1. 选中的 SVG 写进 `web/public/icons/maskable-source.svg`（满幅、无圆角）。
2. 同步 `web/public/favicon.svg`（同图形 + `rx≈232` 圆角）。
3. 在 `web/` 下跑 `npm run icons`。
4. 如果底板不是品牌蓝，把 `web/src/styles.css` 的 `.brand-mark` 底色/勾色改到与图标一致。

## 最终选择（已落地）

- **默认图标：05 签名火漆**（`05-signet.svg`）。已写入
  `web/public/icons/maskable-source.svg`，`npm run icons` 重新生成了 192/512/
  maskable/apple-touch；`web/public/favicon.svg` 是同图形的圆角版。
- **内置图标：第二版全部 5 个 + 经典对勾**。01/02/03/04 的 512 PNG 烘焙在
  `web/src/assets/brand-icons/`，选择后走现有 `/api/branding` 上传链路；
  05 是默认图标，选中它等于清除自定义图标。
- **第一版前四个**不再作为独立图标堆在列表里，收敛成「经典对勾」的四个配色
  色板（金底墨勾 / 深蓝金勾 / 品牌蓝金勾 / 品牌蓝白勾），并支持任意底色和
  图形色。逻辑在 `web/src/lib/builtinIcons.ts`，UI 在
  `web/src/ui/BrandingCard.tsx`。
- 侧栏品牌标记改为直接显示当前图标（默认/自定义）；旧蓝色勾字形已移除。
- 内置材质图标使用构建时烘焙的 PNG，避免浏览器对 SVG 滤镜/图案的差异；
  只有纯色经典对勾在浏览器里走 canvas 栅格化。

默认图标和品牌设置都按现有单租户模型：图标最终是一张 512 PNG 存在中继的
`branding` 行里，没有新增 API 字段或 D1 列。
